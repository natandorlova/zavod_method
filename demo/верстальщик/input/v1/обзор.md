# Макеты v1 · «Переговоры по офферу»

Сценарий v7. Постановка Б, адаптивный веб-модуль.

## С чего начать

1. Откройте [историю](история.html) и нажмите «Перейти к заданию».
2. Откройте [финальную практику](практика.html), выберите ход и обоснование и отправьте ответ. Для проверки двух подсказок выберите А и 2. Для верного ответа выберите Б и 1.
3. Для реализации используйте [инструкции сборки](инструкции.md), [фрагмент сценария v7](сценарий-v7-фрагмент.md) и [визуальные референсы](референсы.md).

Живой текст расположен в HTML-макетах. Для копирования текста каждого состояния откройте [тексты.md](тексты.md).

На телефоне портретная компоновка заменяет две колонки одной. В истории при ширине до 700 px реплика идёт под иллюстрацией, за ней открывается задание. В практике при ширине до 760 px условия и памятка идут перед вариантами, а разбор появляется после ответа ниже формы. Снимки шириной 400 px показывают эту компоновку.

## Состояния

- «Перейти к заданию» раскрывает задание под сценой и переводит фокус на начало задания. Реплика остаётся доступной выше. «Открыть разбор» раскрывает четыре эпизода. Запись наблюдений добровольная и не оценивается.
- В практике участник выбирает по одному ответу в каждой группе. Первая ошибка показывает подсказку у неверной группы. При двух ошибках видны обе подсказки. Поля сохраняют выбор и остаются доступны для исправления. В памятке выделены правила 1 и 4.
- Верная первая или любая вторая попытка открывает полный разбор. Для верного ответа также показывается подтверждение из сценария. Повтор запускает разговор с пустыми полями. Переход ведёт к разговору 2.

## Оформление

Белый фон #FFFFFF, бежевые карточки #F6F2ED, основной текст #000000. Зелёный #01623C для имён говорящих, элементов управления и смысловых акцентов. Оранжевый #E64302 для стрелок и полосок, тёплый серый #908A84 для рамок. На узком экране блоки выстраиваются в одну колонку. Сюжетные иллюстрации выдержаны в живописной рисовке с тёплым светом. Подписи, реплики и инструкции размещены текстом рядом с иллюстрациями.
