# Визуальные референсы курса

| Назначение | Цвет |
| --- | --- |
| Основной фон | `#FFFFFF` |
| Карточки и плашки | `#F6F2ED` |
| Смысловые акценты | `#01623C` |
| Стрелки, полоски и знаки «+» | `#E64302` |
| Вспомогательные детали | `#908A84` |
| Заголовки и основной текст | `#000000` |

В памятках предыдущих модулей ориентиром служат светлые карточки, чёрные заголовки, зелёные контурные пиктограммы и оранжевые навигационные акценты. Сюжетные референсы автора задают тёплый свет и видимую фактуру мазка. Для v1 применена современная офисная постановка.

Принятые визуальные образцы для вёрстки · [сюжетный экран](01-реплика-1200.png), [экран задания](02-ваш-ход-1200.png), [узкий экран практики](03-до-ответа-400.png). Исходные изображения из других модулей доступны в сообщении автора с палитрой в чате согласования. В рабочей копии этих файлов нет.
